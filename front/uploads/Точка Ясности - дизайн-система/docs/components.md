# 02 · Компоненты

Все компоненты доступны сразу после подключения `assets/css/clarity-ui.css`. Разметка ниже совпадает с продакшн-разметкой сайта.

```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">
<link rel="stylesheet" href="assets/css/clarity-ui.css">
```

Спрайт иконок вставляется первым элементом внутри `<body>`, после чего иконка вызывается так:

```html
<svg class="ic"><use href="#i-check"></use></svg>
```

## 1. Кнопки

### Варианты

| Класс | Когда | Спецификация |
|---|---|---|
| `.btn.btn-primary` | Единственное целевое действие экрана | Фон `--blue`, текст белый; hover — подложка `--blue-deep` через псевдоэлемент, подъём 1 px, усиление тени |
| `.btn.btn-gray` | Вторичное действие рядом с главным | Прозрачный фон, контур `inset 0 0 0 1.5px #C5D3E8`; hover — заливка `#E8EDF4` |
| `.btn.btn-white` | Главное действие на тёмном блоке | Градиент `#FFF → #F0F4FA`, текст `--navy`, иконка в синем кружке |
| `.btn.btn-ghost` | Вторичное действие на тёмном блоке | Белый 6 % + `blur(8px)` + контур `rgba(255,255,255,.35)` |

### Геометрия

```
padding: 15px 27px      border-radius: 999px       высота ≈ 48px
font-size: 15px / 700   letter-spacing: -0.01em    white-space: nowrap
gap: 10px               icon: 17 × 17px
transition: .25s cubic-bezier(0.22, 0.72, 0.24, 1)
:active → translateY(1px) за 0.1s
hover иконки → translateX(4px)
≤720px → width: 100%, кнопки в столбик
```

Иконка в `btn-primary` и `btn-white` помещается в кружок 30 px с отрицательными полями — она «выходит» за край кнопки справа.

```html
<a class="btn btn-primary" href="#">Запросить демо<svg class="ic"><use href="#i-arrow-r"></use></svg></a>
<a class="btn btn-gray" href="#">Все продукты</a>
```

**Правило:** одна `btn-primary` на экран. Две синие кнопки рядом — ошибка иерархии.

### Круглая кнопка-стрелка

`.arrow-btn` — 44 × 44 px, контур 1.5 px `#C9D6EA`, иконка 16 px. Живёт в правом углу кликабельных карточек. Сама не нажимается: реагирует на наведение всей карточки — заливается синим, стрелка белеет.

## 2. Карточки

| Компонент | Фон | Радиус | Реакция на наведение |
|---|---|---|---|
| `.card.section` | `#FFFFFF` | 32 px | Нет — это контейнер |
| `.bento-card` | белый / navy-градиент / голубой градиент | 32 px | `translateY(-6px)` + `--shadow-md`, 0.45 s |
| `.product`, `.news-card` | `#F4F7FB` | 22 px | `translateY(-7px)`, фон белеет, `--shadow-md` |
| `.aud-card` | `#FFFFFF` | 22 px | Подъём + тень |
| `.stat` | `#F4F7FB` | 22 px | Лёгкий подъём; цифра анимируется счётчиком 1.1 s |
| `.step`, `.faq-item`, `.product-row` | прозрачный, разделитель сверху | 14 px | Фон `#F4F7FB`, отступ увеличивается |

### Секция

```html
<section class="card section">
  <div class="section-head">
    <div>
      <span class="eyebrow">Продукция</span>
      <h2>Решения под вашу организацию</h2>
    </div>
    <p class="aside-note">Необязательная поясняющая ремарка справа</p>
  </div>
  <!-- содержимое -->
</section>
```

### Bento

12 колонок, карточки на 5 / 7 / 12. Асимметрия обязательна — равномерная решётка из одинаковых плиток противоречит стилю.

```html
<section class="bento">
  <article class="bento-card bento-navy" style="grid-column:span 5">
    <h3>Данные остаются в контуре клиники</h3>
    <p>Разворачиваем на серверах заказчика.</p>
    <div class="bento-meta">
      <span class="bento-pill"><svg class="ic"><use href="#i-shield"></use></svg>152-ФЗ</span>
    </div>
  </article>
  <article class="bento-card" style="grid-column:span 7">…</article>
</section>
```

Модификаторы: `.bento-navy` — тёмный градиент, `.bento-blue` — голубой градиент. **Не более одной тёмной карточки на экран.**

### Карточка продукта

```html
<article class="product">
  <div class="product-ic"><svg class="ic"><use href="#i-scan"></use></svg></div>
  <h3>Название продукта</h3>
  <p>Одно предложение о задаче, которую закрывает продукт.</p>
  <div class="product-foot">
    <span>Категория</span>
    <span class="arrow-btn"><svg class="ic"><use href="#i-arrow-ur"></use></svg></span>
  </div>
</article>
```

Плитка иконки: 48 × 48 px, радиус 16 px, фон `--blue-soft`, иконка синяя. При наведении на карточку инвертируется — фон синий, иконка белая.

## 3. Атомы

### Eyebrow — метка раздела

10 px / 700, капс, трекинг +0.14em, синий на подложке `#E9F0FF`, радиус 999 px, отступы 5.5 / 12 px. Открывает каждую секцию.

```html
<span class="eyebrow">О нас</span>
```

### Пилюля-факт

12 px / 800, фон `#F4F7FB`, радиус 999 px, отступы 7 / 13 px, иконка 13 px синяя.

```html
<span class="bento-pill"><svg class="ic"><use href="#i-shield"></use></svg>152-ФЗ</span>
```

Только проверяемые факты: стандарты, лицензии, сроки, цифры. Не используем для рекламных эпитетов.

### Метрика

```html
<div class="stats-grid">
  <div class="stat"><b>28</b><span>продуктов в экосистеме</span></div>
  <div class="stat"><b>90+%</b><span>точность диагностических моделей</span></div>
</div>
```

Цифра синяя, до 45 px, `tabular-nums`. Подпись 13.5 px / 600 вторичным цветом, строчными, без точки. При появлении в зоне видимости цифра анимируется счётчиком за 1.1 s.

Метрика всегда честная: «2 клиники» лучше, чем «десятки клиник».

### Стеклянный чип

Парящая метка поверх визуала: полупрозрачный белый + `blur(22px)`, радиус 18 px, плавает ±12 px с периодом 7 s. На ≤720 px скрывается.

## 4. Списки-строки

Шаг внедрения, вопрос FAQ, строка продукта — единый паттерн: разделитель сверху, крупный номер слева, при наведении строка подсвечивается фоном `#F4F7FB` и увеличивает отступы.

```html
<div class="steps">
  <div class="step">
    <div class="step-num">01</div>
    <div><h3>Аудит</h3></div>
    <div><p>Смотрим инфраструктуру и текущие сроки.</p></div>
    <div><span class="arrow-btn"><svg class="ic"><use href="#i-arrow-r"></use></svg></span></div>
  </div>
</div>
```

FAQ раскрывается через `grid-template-rows: 0fr → 1fr` — высота анимируется без JS-расчётов; иконка `i-plus` поворачивается на 45°.

## 5. Формы

| Элемент | Спецификация |
|---|---|
| Подпись | 13 px / 700, цвет `--ink-2`, над полем, зазор 7 px. Обязательное — со звёздочкой синего цвета |
| Поле | Фон `#F4F7FB`, радиус 13 px, отступы 13 / 15 px, текст 15 px, граница `inset 0 0 0 1px --line` |
| Фокус | Фон белеет, кольцо `inset 0 0 0 2px --blue` |
| Плейсхолдер | Цвет `--ink-3`, показывает пример, а не повторяет подпись |
| Ошибка | Красное кольцо, текст 12 px под полем; показываем после потери фокуса, не во время набора |
| Чекбокс | Кастомный квадрат 20 px, радиус 6 px, при выборе заливается синим с анимацией «pop» 0.3 s |

```html
<div class="field">
  <label for="email">Электронная почта</label>
  <input id="email" type="email" placeholder="doctor@clinic.ru">
</div>
```

### Модальное окно

Ширина `min(620px, 100%)`, радиус 32 px, скролл внутри, максимум высоты `100dvh − 32px`.
Появление: `translateY(30px) scale(.96) blur(6px)` → норма за 0.65 s; поля выезжают лесенкой с шагом 40 мс через переменную `--d`.

## 6. Навигация

### Сайдбар

264 px, фиксированный, стеклянный, радиус 32 px, отступы 30 / 20 / 22 px. Внутри: блок бренда → группы ссылок с метками `.side-label` → нижний блок с кнопкой.

Пункт: 14 px, отступы 8 / 14 px, иконка 20 px. Активный — синий текст на подложке `--blue-soft`.

На ≤ 1120 px сайдбар уезжает за экран (`translateX(calc(-100% - 32px))`), появляется topbar с бургером; при открытии меню пункты выезжают лесенкой с шагом 40 мс.

### Футер

Градиент `#E7EDF6 → #E0E8F3`, радиус 40 px, внутренний блик сверху. Сетка `1.5fr 1fr 1fr 1.25fr`: блок бренда с пилюлями, две колонки ссылок, колонка контактов с кнопкой и соцсетями. Нижняя строка — правовые ссылки.

### CTA-блок

Тёмный градиент под 150°, радиус 40 px, текст по центру, отступы `clamp(52px, 6vw, 92px)`. Внутри — две декоративные окружности с полупрозрачной обводкой (`::before` 560 px слева-сверху, `::after` 640 px справа-снизу). Кнопки: `btn-white` + `btn-ghost`.

## 7. Иконки

37 иконок одного набора.

```
viewBox: 0 0 24 24
fill: none · stroke: currentColor · stroke-width: 1.8
stroke-linecap: round · stroke-linejoin: round
```

Размеры: 13 px в пилюле · 16 px в стрелке · 17 px в кнопке · 20 px в навигации · 22–26 px в плитке 48 × 48.

Полный список: `i-home`, `i-info`, `i-scan`, `i-grid`, `i-layers`, `i-users`, `i-book`, `i-arrow-r`, `i-arrow-d`, `i-arrow-ur`, `i-check`, `i-pulse`, `i-spark`, `i-shield`, `i-clock`, `i-rotate`, `i-plus`, `i-minus`, `i-monitor`, `i-flask`, `i-video`, `i-gauge`, `i-archive`, `i-doc`, `i-play`, `i-code`, `i-mail`, `i-building`, `i-target`, `i-download`, `i-cube`, `i-phone`, `i-quest`, `i-tg`, `i-max`, `i-vk`, `i-github`.

**Новая иконка:** сетка 24 × 24, обводка ровно 1.8, скруглённые концы, минимум деталей — иконка должна читаться при 13 px. Заливки нет, кроме точек-акцентов. Имя с префиксом `i-`.

Иконки из других наборов и эмодзи не используются.
