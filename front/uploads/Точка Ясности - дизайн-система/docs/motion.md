# 03 · Анимация

Движение в системе объясняет структуру, а не развлекает. Оно быстрое на действия пользователя и мягкое на появление контента.

---

## 1. Кривые

| Токен | Значение | Где |
|---|---|---|
| `--ease` | `cubic-bezier(0.22, 0.72, 0.24, 1)` | Все интерфейсные реакции: кнопки, наведение, поля, раскрытие FAQ, смена фона |
| `--ease-soft` | `cubic-bezier(0.22, 1, 0.36, 1)` | Появление контента при скролле, вход модального окна |

Обе кривые быстро стартуют и мягко тормозят. `ease-soft` тормозит дольше — движение выглядит «дорогим». Стандартные `ease`, `linear`, `ease-in-out` не используются.

---

## 2. Длительности

| Время | Сценарий |
|---|---|
| 0.1 s | Нажатие: `translateY(1px)` |
| 0.25 s | Кнопки, поля ввода, сдвиг иконки на 4 px |
| 0.3 s | Круглая кнопка-стрелка, чекбокс |
| 0.35 s | Иконки, строки списков, смена фона, увеличение отступов |
| 0.4–0.45 s | Карточки: подъём и тень |
| 0.5 s | Модальная подложка, сайдбар (тень) |
| 0.65 s | Появление модального окна |
| 0.7 s | Выезд бокового меню на мобильных |
| 0.9 s | Появление секции при скролле |
| 7 s | Парение чипа, бесконечный цикл ±12 px |

---

## 3. Появление при скролле

Элемент с классом `.reveal` изначально прозрачен. При входе в зону видимости (`IntersectionObserver`, порог 0, нижняя граница −8 %) добавляется класс `.in` и проигрывается анимация. Наблюдение снимается — повторно элемент не анимируется.

```css
html.js .reveal      { opacity: 0; }
html.js .reveal.in   { opacity: 1; animation: reveal-in .9s var(--ease-soft) var(--d, 0s) backwards; }

@keyframes reveal-in {
  from { opacity: 0; transform: translateY(26px); }
  to   { opacity: 1; transform: translateY(0); }
}
```

Карточки и метрики приезжают с дополнительным размытием и масштабом — это создаёт ощущение глубины:

```css
@keyframes reveal-in-card {
  from { opacity: 0; transform: translateY(38px) scale(.988); filter: blur(8px); }
  55%  { filter: blur(0); }
  to   { opacity: 1; transform: translateY(0) scale(1); filter: none; }
}

@keyframes reveal-in-stat {
  from { opacity: 0; transform: translateY(26px) scale(.96); filter: blur(5px); }
  55%  { filter: blur(0); }
  to   { opacity: 1; transform: translateY(0) scale(1); filter: blur(0); }
}
```

### Лесенка

Элементы одной группы выходят не одновременно: старт 0.1 s, шаг 0.04 s, максимум 8–10 элементов в цепочке.

```html
<div class="reveal" style="--d:.1s">…</div>
<div class="reveal" style="--d:.14s">…</div>
<div class="reveal" style="--d:.18s">…</div>
```

## 4. Реакции на наведение

| Элемент | Реакция |
|---|---|
| `btn-primary` | Подъём 1 px, подложка уходит в `--blue-deep`, тень усиливается |
| `btn-gray` | Заливка `#E8EDF4`, контур темнеет |
| Иконка в кнопке | `translateX(4px)` |
| `bento-card` | `translateY(-6px)` + `--shadow-md` |
| `product`, `news-card` | `translateY(-7px)`, фон белеет, `--shadow-md` |
| Плитка иконки | Фон синий, иконка белая |
| `arrow-btn` | Заливается синим, стрелка белеет (срабатывает от наведения на карточку) |
| Строка списка | Фон `#F4F7FB`, отступы увеличиваются |
| Блок бренда | Знак `scale(1.06)` |

Все реакции обратимы и не смещают соседние элементы.

---

## 5. Загрузка страницы

До готовности документа (`html.js:not(.is-loaded)`) сайдбар, шапка и первый экран удерживаются в смещённом прозрачном состоянии. После — выходят по очереди: сайдбар → блок бренда → пункты навигации → заголовок → лид → кнопки → факты → визуал. Это устраняет мигание нестилизованного контента и задаёт ритм чтения.

---

## 6. Счётчик метрик

При появлении блока метрик цифра анимируется от нуля до целевого значения за 1.1 s с кубическим замедлением (`1 − (1 − t)³`). Формат числа сохраняется: разделитель — запятая, префиксы и суффиксы («+», «%») остаются на месте.

---

## 7. Обязательное: prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  *, ::after, ::before {
    animation-duration: 0s !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0s !important;
  }
  html.js .reveal { transition: opacity .45s ease var(--d, 0s) !important; }
  html.js .reveal.in { animation: none !important; }
}
```

Все смещения и трансформации отключаются, остаётся только плавное появление прозрачности. Это требование доступности, а не опция.

---

## 8. Чего не делаем

- Параллакс-скролл и «залипающие» анимированные секции.
- Автопроигрывающиеся карусели.
- Появление элементов по одному дольше 10 в цепочке.
- Анимации длиннее 1 s для интерфейсных реакций.
- Пружинные и «прыгающие» кривые (`overshoot`) на кнопках.
- Мигание, пульсация и бесконечные анимации вне декоративных чипов.
