# 06 · Готовые промпты для Claude

Чтобы Claude делал материалы в стиле «Точки Ясности», ему нужны две вещи: правила и компоненты. Ниже — три способа их дать, от самого надёжного к самому быстрому.

---

## Способ 1 — проект в Claude Design (рекомендуется)

В аккаунте создан design-system проект **«Точка Ясности — дизайн-система»**. В нём лежат превью компонентов, слайдов, токены и документы с запретами. Claude видит их и опирается на них при генерации.

Как пользоваться: откройте [claude.ai/design](https://claude.ai/design), выберите проект и пишите задачу обычными словами.

```
Сделай презентацию на 8 слайдов для главврача о нашей ИИ-диагностике маммографии.
Используй дизайн-систему проекта: слайды 16:9, светлый фон по умолчанию,
тёмный градиент только на обложке и контактах. Структура: обложка, проблема,
решение, как работает, цифры, внедрение, кому подходит, контакты.
```

```
Собери лендинг продукта «Протокол» на нашей дизайн-системе:
первый экран, три преимущества в bento, метрики, этапы внедрения, FAQ, CTA.
```

Обновить проект, когда система изменится, можно этой же командой в Claude Code:
«обнови проект Точка Ясности в Claude Design из папки Disign-Tochka-Yasnosti».

## Способ 2 — обычный чат или проект Claude

Приложите к чату два файла:

- `docs/00-brief.md` — правила и запреты;
- `assets/css/clarity-ui.css` — все компоненты.

Для слайдов и веб-страниц дополнительно приложите `brandbook/presentation-template.html` или `starter/landing.html` — Claude возьмёт их за основу разметки.

Промпт:

```
Во вложении дизайн-система «Точка Ясности»: brief с правилами и clarity-ui.css
со всеми компонентами. Сделай <что нужно>, строго соблюдая систему.

Обязательно:
— подключи Manrope и clarity-ui.css, пользуйся готовыми классами, свой CSS пиши
  только для того, чего в ките нет;
— светлый фон #EDF1F7, белые карточки, радиус 32px, зазор 24px;
— один акцент #2456E6: одна главная кнопка на экран;
— чёрный фон и чёрный текст запрещены, тёмный — это градиент #0B1D4E → #122E7E;
— иконки только из спрайта (<svg class="ic"><use href="#i-check"></use></svg>);
— без стоковых фото, эмодзи, рамок вокруг карточек и серых теней;
— тексты: спокойно, конкретно, каждая цифра с опорой на факт.
```

## Способ 3 — быстрый промпт без вложений

Скопируйте это целиком, когда файлов под рукой нет.

```
Работай в дизайн-системе «Точка Ясности» (медицинское ПО). Правила:

ЦВЕТ (других не бывает):
фон #EDF1F7 · поверхность #FFFFFF · вложенная #F4F7FB · линия #E2E8F2
текст #0C1A33 / #45536D / #5C6D89
акцент #2456E6, hover #1B41C0, подложка #E9F0FF, светлый #D9E5FA
тёмный градиент linear-gradient(150deg, #0B1D4E 0%, #122E7E 85%)
голубой градиент linear-gradient(150deg, #E6EFFC 0%, #C9DCF8 100%)

ЗАПРЕЩЕНО: чёрный фон и чёрный текст (#000 в любом виде), цвета вне палитры,
тёплые оттенки, серые тени, рамки вокруг карточек, второй шрифт, начертания
легче 400, курсив, эмодзи, стоковые фото людей, две синие кнопки рядом,
два тёмных блока на одном экране, скругления вне шкалы.

ШРИФТ: Manrope 400–800.
H1 clamp(38px,4.3vw,62px)/800/−0.03em/1.08 · H2 clamp(30px,3.1vw,46px)/700/−0.035em
H3 19px/800 · лид clamp(16px,1.25vw,18px)/1.7 цвет #45536D · текст 16px/1.6
кнопка и поле 15px/700 · подпись 13.5px/600 · пилюля 12px/800
eyebrow 10px/700 капс +0.14em синий на #E9F0FF
метрика clamp(33px,2.9vw,45px)/700 синяя, tabular-nums

ФОРМА: радиусы 40 (CTA, футер) / 32 (карточка-секция) / 22 (вложенная) /
14 (строка) / 16 (плитка иконки 48×48) / 13 (поле) / 999 (кнопки и пилюли).
Тени синие: 0 18px 44px -20px rgba(14,42,102,.14). Границы — inset box-shadow,
не border.

СЕТКА: оболочка до 1774px, контент до 1460px, сайдбар 264px, внешний отступ 26px,
зазор 24px, отступ секции clamp(34px,3.6vw,56px) / clamp(28px,3.4vw,56px).
Сетка карточек 3 колонки gap 18px → 2 на 1280px → 1 на 720px.
Bento — 12 колонок, карточки span 5 / 7 / 12, асимметрия обязательна.
На 1120px сайдбар превращается в выдвижное меню с бургером.

ДВИЖЕНИЕ: интерфейс .25s cubic-bezier(0.22,0.72,0.24,1);
появление .9s cubic-bezier(0.22,1,0.36,1), лесенка с шагом 40мс;
карточка при наведении поднимается на 6–7px и получает тень.
При prefers-reduced-motion остаётся только opacity.

ИКОНКИ: контурные, viewBox 0 0 24 24, stroke-width 1.8, currentColor,
скруглённые концы. Никаких заливок и чужих наборов.

ТОН: спокойно, конкретно, на языке клиента. Каждое утверждение подкреплено
цифрой, стандартом или сроком (152-ФЗ, HL7/FHIR, DICOM, 24/7). Без «революции»,
«уникального» и «прорыва». ИИ помогает врачу, а не заменяет его.
Кнопка — глагол в инфинитиве, 1–3 слова. Кавычки «ёлочки», тире длинное.

ПРЕЗЕНТАЦИИ: слайд 1280×720 (16:9), поля 64px по вертикали и 76px по горизонтали.
Фон слайда — один из четырёх: #EDF1F7, #FFFFFF, голубой градиент, тёмный градиент.
Тёмных слайдов не больше четверти, обычно обложка и контакты.
Заголовок слайда 52px/800, обложки 66px, лид 19px, минимальный кегль 9pt.
Одна мысль на слайд, максимум 6 объектов, скругления карточек 24px.
Сверху знак и название слева, eyebrow-метка справа; снизу колонтитул и номер.
```

## Что проверить в результате

- [ ] Фон светлый, чёрного нет
- [ ] Все цвета из палитры
- [ ] Manrope, начертания от 400
- [ ] Скругления из шкалы бренда
- [ ] Тени синие, рамок нет
- [ ] Одна синяя кнопка, один тёмный блок
- [ ] Иконки контурные 1.8, эмодзи нет
- [ ] Цифры с опорой на факт
