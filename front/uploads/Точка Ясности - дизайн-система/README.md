# Дизайн-система «Точка Ясности»

Единая база визуального языка компании. Один набор токенов и компонентов, из которого собираются **сайты, веб-интерфейсы продуктов и презентации** — так, чтобы всё выглядело частью одной экосистемы.

Значения извлечены из продакшн-стилей [tochka-yasnosty.ru](https://tochka-yasnosty.ru/), а не восстановлены на глаз — они совпадают с сайтом до пикселя.

---

## Ядро системы — один файл

```html
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">
<link rel="stylesheet" href="assets/css/clarity-ui.css">
```

`assets/css/clarity-ui.css` — это вся система: токены, типографика, кнопки, карточки, bento, пилюли, метрики, формы, модалка, навигация, футер, анимация. Больше ничего писать не нужно.

## С чего начать

| Задача | Что открыть |
|---|---|
| **Сделать презентацию** | `brandbook/presentation-template.html` — 11 типов слайдов 16:9, печатается в PDF |
| **Собрать сайт или лендинг** | `starter/landing.html` — готовый каркас страницы |
| **Собрать веб-морду продукта** | `starter/app.html` — каркас внутреннего интерфейса с таблицей и панелью |
| **Понять правила** | `brandbook/index.html` — визуальный брендбук |
| **Передать подрядчику или нейросети** | `docs/00-brief.md` — сжатое ТЗ на одной странице |
| **Работать в Figma** | `tokens/figma-tokens.json` — импорт через плагин Tokens Studio |

Открывать локально через сервер, иначе браузер заблокирует часть ресурсов:

```bash
cd /home/robot/Documents/Disign-Tochka-Yasnosti
python3 -m http.server 8080
# http://localhost:8080/brandbook/
```

## Дизайн в одном абзаце

Холодный светло-серый холст `#EDF1F7`, на нём — белые карточки со скруглением 32 px и зазором 24 px. Слева фиксированный «стеклянный» сайдбар 264 px. Шрифт один — Manrope; заголовки крупные, на отрицательном трекинге, текст просторный. Акцент ровно один — синий `#2456E6`, им маркируется действие и метрика, а не украшение. Тени синие и мягкие, рамок вокруг карточек нет. Тёмные блоки — градиент navy под 150°, не больше одного на экран. Движение быстрое на действия (0.25 s) и мягкое на появление (0.9 s), при `prefers-reduced-motion` отключается.

```
Вложенная     #F4F7FB      Подложка      #E9F0FF      Сайдбар   264 px
Текст         #0C1A33      Тёмный        #0B1D4E      Отступ    26 px
Вторичный     #45536D      Тёмный 2      #122E7E      Зазор     24 px
Линия         #E2E8F2      Шрифт         Manrope 400–800
```

Кривая интерфейса `cubic-bezier(0.22, 0.72, 0.24, 1)` · кривая появления `cubic-bezier(0.22, 1, 0.36, 1)`

## Главные запреты

- **Чёрный фон — никогда.** Ни `#000000`, ни «почти чёрный». Тёмный в бренде — это синий `#0B1D4E`.
- **Чёрный текст — тоже нет.** Основной текст `#0C1A33`.
- **Цвета только из палитры.** Никаких зелёных «успехов» и оранжевых «вниманий» в макетах.
- **Один акцент, одна главная кнопка, один тёмный блок** на экран или слайд.
- **Второй шрифт, начертания легче 400, курсив** — не используем.
- **Серые тени, рамки вокруг карточек, острые углы** — не используем.
- **Стоковые фото людей, эмодзи, чужие иконки** — не используем.

Развёрнуто с объяснениями — в `docs/00-brief.md` и в разделе «Как применять» брендбука.

---

## Обновление

Если сайт изменится, `source/` перестанет совпадать с продакшном. Порядок: заново снять `assets/css/style.css` и страницы, сверить блок `:root`, обновить `tokens/*` и раздел «Цвет» брендбука. Блок CORE в `tokens.css` — зеркало сайта, вручную его не правят.
