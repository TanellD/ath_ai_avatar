# Конкурентный ландшафт: аналоги и дифференциация

Собрано по открытым источникам (сайты вендоров, обзоры, агрегаторы отзывов) в сентябре 2026, top-down, без прямого контакта с вендорами. Цены и позиционирование не проверялись у самих компаний — держать как ссылочный материал для защиты, а не как заявленный факт. Где данные не подтверждены независимо, это явно помечено.

## Аналоги

Global-игроки в основном закрывают продажи. Вербо — единственный найденный прямой конкурент на рынке РФ с сопоставимым стеком (сценарии + AI-персонажи + аудио/видео-диалог + оценка).

| Игрок | Рынок | Что делает | Сила | Жалобы пользователей |
|---|---|---|---|---|
| Second Nature | Global | AI-roleplay для обучения продажам: сценарии, AI-персоны, голосовой диалог, автоматическая оценка | Зрелый продукт, масштабирование обучения | Предсказуемость сценариев — можно «натренироваться на систему» и получить высокий score без реального улучшения навыка |
| Hyperbound | Global | Тренажёр продаж с кастомными персонажами, scorecards и аналитикой | Реалистичность диалога, гибкие боты | Задержки, повторяемость сценариев при частом использовании, game the bot, трудоёмкая первоначальная настройка |
| Virti | Global | Корпоративные roleplay-тренировки с виртуальными персонажами для soft skills и сложных разговоров | Охват soft-skills сценариев за пределами продаж | Latency, недостаточно естественные голоса и эмоции, ограниченный выбор голосов, некомфортный визуальный образ аватара |
| Yoodli | Global | AI-тренер для roleplay и коммуникационных навыков с детальной обратной связью | Сильная оценка темпа, ясности, манеры речи | Слабее оценивает содержание и стратегию ответа, задержки, сложная настройка backend |
| Вербо | РФ | Российская платформа корпоративных AI-симуляций: сценарии, AI-персонажи, аудио/видео-диалоги, критерии оценки, аналитика | Готовые интеграции с российскими СДО (ТренингСпэйс, Эквио, iSpring Learn, WebSoft HCM, Mirapolis, Moodle) — методисту не нужно менять систему, где уже живёт LMS | Независимых отзывов о реальном UX мало; функционально ближе всего к целевому решению из всех найденных |

## Боли пользователей аналогов → чем отвечаем

Каждая жалоба сопоставлена с конкретным решением продукта, а не общим «у нас лучше».

| Боль аналогов | Ответ в продукте | Статус |
|---|---|---|
| Предсказуемость персонажа — после нескольких попыток учишься проходить конкретного бота | Настроение и сложность персонажа варьируются между прогонами одного сценария — тот же сценарий не проходится одинаково дважды | уже есть |
| Score gaming — высокий балл за нужные слова без доказанного улучшения навыка | Каждый балл несёт дословную цитату из транскрипта и аудио-фрагмент под ней — балл нельзя получить за фразу, которой не было сказано | уже есть |
| Недостаточная вариативность — повторяются персонажи, возражения, ветки разговора | Частично закрыто вариацией настроения/сложности персонажа (предварительно подтверждено на трёх разных контекстах диалога); широта библиотеки персон и возражений растёт вместе с числом сценариев в системе | в работе |
| Latency и неестественный ритм — заметные паузы между репликами ломают ощущение живого разговора | Озвучивание ответа по частям без ожидания полной генерации; первый звук — не позднее 3 с; при перебивании речь персонажа останавливается за ≤300 мс | уже есть |
| Слабая объяснимость оценки — системы лучше оценивают форму речи, чем стратегию ответа | Под каждым баллом рубрики — цитата, короткий аудио-фрагмент (~5 с) и уровень уверенности распознавания как визуальный флаг «перепроверь на слух» | уже есть |
| Высокие трудозатраты методиста на создание тренировок — ручная настройка сценариев, персонажей, критериев | Методист вводит краткое описание сценария и несколько настроек — весь сценарий (персонаж, этапы, критерии, вступительная реплика) генерируется нейросетью целиком | уже есть |
| Искусственность голоса и аватара — почти реалистичный персонаж усиливает эффект «неживого» собеседника | Ставка на характер персонажа, а не на фотореализм — осознанный отказ от фотореалистичного видеоперсонажа как продуктовое решение | в работе — зависит от финального выбора рендера лица |
