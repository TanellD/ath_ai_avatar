# Монетизация: модель и ориентир цены

Модель монетизации: **подписка на активных сотрудников плюс тарификация по
минутам**. Ниже — во что это разворачивается по тарифным планам, и на каких
цифрах юнит-экономики это стоит.

## Почему не чистый per-seat и не чистый usage-only

Чистый per-seat (фиксированная цена за сотрудника вне зависимости от того,
сколько он тренируется) не отражает переменную часть себестоимости — голосовой
стек (распознавание речи + LLM + синтез речи + рендер лица) стоит денег за
минуту, а не за факт доступа. Чистый usage-only не отражает роль методиста:
конструктор сценариев (включая автогенерацию сценария по краткому описанию)
создаёт ценность независимо от того, сколько минут наговорено сотрудниками.
Нужны обе составляющие, ни одна не заменяет другую.

## Тарификация по минутам: от чего считать цену

Фактическая себестоимость минуты (распознавание и синтез речи уже включены в
цифру, посчитана на реальной модели и реальной цене GPU):

| Конфигурация | ₽/мин |
|---|---|
| Локально, GPU по цене покупки, 3 года амортизации, 500 тренировок/мес | 2,60 |
| Локально, тот же GPU, 5 лет амортизации, 1000 тренировок/мес | 1,63 |
| Локально, GPU по текущей рыночной цене (выросла с момента покупки), 3 года, 500 тренировок/мес — худший случай | 3,99 |
| Через облачный API вместо собственной инфраструктуры | 1,40 (не зависит от объёма) |

При тренировке 10 минут себестоимость сессии — **≈14–40 ₽** в зависимости от
конфигурации и объёма.

**Сверка с рынком.** Ближайший российский аналог продаёт тариф «Старт» по
11 700 ₽/мес за до 80 сессий — это ≈146 ₽/сессию розничной цены. Даже в
худшем случае себестоимости (40 ₽/сессию) это уже даёт запас ×3,7 к рыночной
цене конкурента; на самой дешёвой конфигурации (14 ₽/сессию) запас ×10. Это
не наша целевая цена, а проверка на правдоподобность: рынок уже платит за
сессию сумму, кратно превышающую посчитанную себестоимость.

## Тарифная сетка (гипотеза, не проверена пилотом)

| План | Кому | Что входит | Ось тарификации |
|---|---|---|---|
| **Старт** | Пилот, 1 отдел | Готовые шаблоны сценариев, автогенерация своих (краткое описание → полный сценарий), 1 методист, ограниченный пул сессий/мес | подписка за активных сотрудников + пул сессий, оверейдж по минутам сверх пула |
| **Бизнес** | Компания с несколькими отделами | Свои сценарии без ограничений, несколько методистов, аналитика по когортам, поиск по собственной базе знаний компании | то же + больше активных сотрудников |
| **Enterprise** | Крупный заказчик | Единый вход (SSO), интеграция с LMS/СДО, индивидуальный SLA | индивидуально |

Поиск по клиентской базе знаний — намеренно ось перехода Старт → Бизнес: он
требует настройки под конкретного клиента (higher touch), это оправдывает
более высокий тариф, а не бесплатная фича входа.

## Что не закрыто

Себестоимость посчитана только для собственной инфраструктуры — пересчёт под
конкретного облачного провайдера при иной конфигурации не проводился. Главное:
**экономика подписки не проверена реальным ценообразованием на пилоте**.
Тарифная сетка выше — гипотеза для следующего шага (пилот на 1–2 отделах с
реальными методистами), не прайс-лист.
